# OPENIV
In first, modify a gtaV file need an another applcation. 
Application is named [OpenIV](https://openiv.com/)(official website), 
If you don't like russian website, you can download it [here](https://fr.gta5-mods.com/tools/openiv).

In addition to, if you don't want to break your entire game, we need to create a backup.
In the root of the game, create a folder "*mods*" and copy *update* folder in *mods* folder.

An add-on is an item or a pack of items that is added on top of those in the base game. You therefore need to tell the game that this item or these items exist.
To do this, you edit the dlclist.xml file.
Next, you need to tell the game to load this item or these items; otherwise, the game won’t understand and will crash.
You use a gameconfig.xml file. 
At the day, we know gameconfig which do a good job : [Game Config](https://www.gta5-mods.com/misc/gta-5-gameconfig-300-cars)
I advice u to take '0.5x traffic'
Place it into -> mods > update > update.rpf > common > data *(via OpenIV)* (il faut être en edit mode)

A problem : if we load more files, we need a bigger cache. So we take a [heapadjuster](https://www.gta5-mods.com/tools/heapadjuster). 
Juste need to drag *heapadjuster* content in the root of the game

After that, if you want to add some vehicules... you will especially into openIV mods > update > ...
Just read the readme to know further
